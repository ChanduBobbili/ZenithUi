# @zenithui/grid-layout

## 0.1.0

### Minor Changes

- Initial release of `@zenithui/grid-layout`
  - Drag-and-drop cell reordering (swap, insert-left/right, eject to new row)
  - Drag-and-drop row reordering
  - Live column and row resizing with framer-motion animated handles
  - 12-column snap grid on column resize release
  - Readonly mode, per-cell/per-row `reorderable` and `resizable` flags
  - Full render-prop API: `renderItem`, `renderDragHandle`, `renderRowControls`, `renderEmptyState`
  - Exported pure layout utility functions
