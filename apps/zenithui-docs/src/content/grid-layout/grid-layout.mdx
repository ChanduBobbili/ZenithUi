# Grid Layout

The interactive grid layout supports full drag-and-drop and resize interactions.

## Demo

<BasicDemo />

## Interactions

- **Cell drag-and-drop** — swap cells, insert left/right (25% edge threshold), or drop into a new row via the strips between rows
- **Row drag-and-drop** — drag a row to swap with another row
- **Column resize** — drag the handle between adjacent cells; widths snap to a 12-column grid on release
- **Row resize** — hover between rows to reveal the row resize handle, then drag vertically
